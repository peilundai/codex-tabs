# Support

This extension is unofficial and is not supported by OpenAI.

For extension launch, tab placement, or path-insertion issues, use the issue
tracker declared in `package.json` and include the VS Code version, extension
version, operating system, local/remote environment, and relevant Codex CLI
output-channel logs. Remove private paths and secrets first.

For Codex CLI authentication, models, permissions, sessions, or CLI behavior,
use the [official Codex documentation](https://developers.openai.com/codex/cli/features).
